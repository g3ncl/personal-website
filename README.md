# Personal Website

A minimalist personal website serving as my online portfolio and resume. Built with **Next.js** and **TypeScript**, styled using **SCSS Modules**.

🔗 **Live at:** [g3n.cl](https://g3n.cl)

## 🚀 Features

- **One-page design** – Showcases my work experience, projects, and contact details.
- **Resume downloads** – Available in **English** and **Italian** from [github.com/g3ncl/resume](https://github.com/g3ncl/resume/releases).
- **Social links** – Direct access to my [GitHub](https://github.com/g3ncl) and [LinkedIn](https://www.linkedin.com/in/g3ncl).

## 🛠 Tech Stack

- **Next.js**
- **TypeScript**
- **SCSS Modules**
- **Lucide React**
- **Twemoji Country Flags** (Ensures proper flag emoji display in Chromium browsers on Windows)
