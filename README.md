# Personal Website

Minimal personal website built with [Astro](https://astro.build/) and vanilla CSS.

## Stack

- **Astro** — Static site generator
- **Vanilla CSS** — No frameworks, just CSS custom properties
- **Zero client JavaScript** — Fully static

## Development

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```

Static files are generated in `dist/`.
